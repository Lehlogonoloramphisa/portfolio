# Lehlogonolo Ramphisa | Azure and Fabric Data Engineer

An accessible, responsive static portfolio focused on data engineering across Microsoft Azure and Microsoft Fabric. The site is built with HTML, CSS, and JavaScript and has no build step.

## Preview locally

```powershell
python -m http.server 5173
```

Open `http://localhost:5173/`.

## Featured projects

- [Banking Transaction Fraud Analytics](https://github.com/Lehlogonoloramphisa/Banking-Transaction-Fraud-Analytics) — Fabric, PySpark, Delta Lake, and Power BI.
- [E-commerce Data Engineering](https://github.com/Lehlogonoloramphisa/Microsoft-Fabric-E-commerce_Data_Engineering) — metadata-driven ingestion, PySpark transformations, and analytical Delta tables.
- [SureLink Short-Term Insurance Data Engineering](https://github.com/Lehlogonoloramphisa/Short-Term_Insurance_Data-Engineering) — Azure SQL ingestion, Fabric Dataflow Gen2, PySpark quality checks, and a Gold claims model.

## Files

- `index.html` — portfolio content, metadata, structured data, and project case studies.
- `styles.css` — responsive layout, typography, accessibility states, and architecture diagrams.
- `script.js` — mobile navigation, section tracking, and interactive architecture stages.
- `profile pictures/` — optimized profile image.
- `Resume/` and `Certifications/` — documents linked from the site.

The project metrics shown on the site are documented results from the linked repositories and saved notebook outputs.
